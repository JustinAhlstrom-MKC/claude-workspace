# Claude workspace

Working folder for Cowork. Files Claude and I create and edit live here.

## Folders
- `mkc/` — restaurant work (Margie's, Grackle, shared back end)
- `home/` — personal and family
- `scratch/` — throwaway drafts; safe to empty anytime

## Rules
- Add a new folder only after hitting real friction twice.
- Not inside Google Drive / iCloud / OneDrive / Dropbox (sync breaks Cowork).
- Not the same as `C:\Users\justi\.claude` — that's Claude's settings folder. No work files there.
- Live Google Docs/Sheets: use the Google Drive connector, not this folder.
- Finished deliverables to share: copy to Drive.
- Backup: private GitHub repo (`git push` after a work session).
